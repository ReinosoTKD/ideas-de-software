# Investigación — 29 de octubre de 2026, 10:00 a. m. (GYE)

## Tema
**¿Cuáles son las mejores ideas para crear y desarrollar software, apps y negocios virtuales?**

Perfil considerado: 15 años, recursos limitados, enfoque legal, seguro, ético y de bajo costo.

## Conclusión rápida
La oportunidad más realista no es crear una app genérica con inteligencia artificial. Es resolver un problema pequeño, repetido y específico para un grupo cercano, comprobar que realmente lo necesitan y crear una primera versión sencilla.

Los negocios pequeños están usando IA principalmente en productividad, marketing, atención al cliente, análisis y automatización. Eso abre oportunidades para herramientas prácticas y fáciles de adoptar, no para productos complejos.

## Ideas recomendadas

### 1. Panel para academias deportivas
Una web para registrar asistencia, horarios, pagos pendientes y avisos por WhatsApp para una academia de taekwondo, fútbol, baile o gimnasio.

- **Por qué puede funcionar:** es un problema concreto; puedes hablar con usuarios reales y entender sus necesidades.
- **Habilidades:** HTML, CSS, JavaScript; después, base de datos sencilla.
- **Herramientas gratuitas:** GitHub Pages para la primera página; Firebase Spark para autenticación o datos básicos.
- **Dificultad:** media.
- **Tiempo para una primera versión:** 2–4 semanas.
- **Costo:** $0 al inicio.
- **Riesgo:** no almacenar datos sensibles de alumnos ni pagos reales sin autorización y medidas de seguridad.

### 2. Servicio de contenido para negocios locales
Un servicio que entregue publicaciones, textos, diseños y un calendario semanal para tiendas, restaurantes, peluquerías o entrenadores.

- **Por qué puede funcionar:** muchas personas necesitan publicar con regularidad, pero no tienen tiempo.
- **Habilidades:** redacción, diseño básico, comunicación y organización.
- **Herramientas gratuitas:** Canva, Google Drive, GitHub Pages como portafolio.
- **Dificultad:** baja.
- **Tiempo:** 1 semana para conseguir ejemplos y validar con usuarios.
- **Costo:** $0.
- **Riesgo:** verificar los datos antes de publicar; no usar fotos ni marcas sin permiso.

### 3. Página de recursos para estudiantes
Una web con planificador de tareas, calculadora de notas, técnicas de estudio, recursos gratuitos y oportunidades verificadas.

- **Por qué puede funcionar:** tú mismo conoces los problemas de estudiantes.
- **Habilidades:** diseño web y JavaScript básico.
- **Herramientas gratuitas:** GitHub Pages, HTML/CSS/JavaScript.
- **Dificultad:** baja-media.
- **Tiempo:** 1–3 semanas.
- **Costo:** $0.
- **Riesgo:** no recopilar información personal de otros menores.

### 4. Mini-sitios para negocios de barrio
Páginas simples con servicios, precios, ubicación, horario, catálogo y botón de contacto por WhatsApp.

- **Por qué puede funcionar:** muchos negocios todavía no tienen una presencia digital clara.
- **Habilidades:** HTML, CSS, diseño básico y conversación con clientes.
- **Herramientas gratuitas:** GitHub Pages.
- **Dificultad:** baja.
- **Tiempo:** 2–5 días por sitio al comienzo.
- **Costo:** $0.
- **Riesgo:** usar solo información, imágenes y logos autorizados por el negocio.

### 5. Directorio local de clases y servicios
Una página que reúna tutores, clubes, actividades, técnicos o clases de la zona.

- **Por qué puede funcionar:** facilita encontrar opciones sin depender solo de redes sociales.
- **Habilidades:** investigación, diseño web y organización de datos.
- **Herramientas gratuitas:** GitHub Pages y una hoja de cálculo.
- **Dificultad:** media.
- **Tiempo:** 2–4 semanas.
- **Costo:** $0–15.
- **Riesgo:** pedir permiso antes de publicar datos de contacto y mantener la información actualizada.

## Recomendación principal
Empieza con el **panel para academias deportivas**. Es específico, puede probarse con pocas personas y aprovecha un entorno que podrías conocer. No intentes incorporar IA desde el inicio: primero resuelve asistencia, horarios y avisos. Si las personas lo usan, añade funciones gradualmente.

## Plan de acción de 30 días

1. Habla con cinco posibles usuarios y pregunta qué tarea les toma más tiempo.
2. Escribe una sola función principal que tu versión inicial deba resolver.
3. Dibuja la pantalla en papel o Canva.
4. Construye una versión web simple.
5. Pide a tres usuarios que la prueben y observa dónde se confunden.
6. Mejora solo lo que se repite en sus comentarios.
7. Publica el proyecto y úsalo como parte de tu portafolio.

## Seguridad y legalidad
- No prometas ganancias ni resultados que no puedas demostrar.
- No uses cuentas de pago, contratos o cobros de terceros sin hablarlo con un adulto de confianza.
- No almacenes contraseñas, documentos, ubicaciones precisas ni datos personales innecesarios.
- Pide permiso para fotos, logos, nombres y contactos.
